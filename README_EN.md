## Project Overview
PostShare is a web application implemented using three popular front-end frameworks: React, Vue, and Angular. The project aims to demonstrate different approaches to building web applications and to compare these frameworks in terms of performance, flexibility, and ease of use.

## Features
- **User Registration and Login:**  
  Users can create new accounts and log in to access the full functionality of the app.

- **Post Management:**  
  Authenticated users can browse, add, edit, and delete posts. Each post contains details such as title, content, author, and creation date.

- **User Profile Management:**  
  Users can manage their profiles and edit personal information.

- **Server Communication:**  
  The application communicates with the backend server using HTTP requests via a RESTful API.

## Technologies Used
- React, Vue, Angular (front-end frameworks)
- RESTful API for server communication
- Netlify for deployment

## Getting Started

### React
1. Navigate to the `react-app` directory.  
2. Install dependencies with:  
   ```bash
   npm install
   ```  
3. Start the application:  
   ```bash
   npm start
   ```  
4. Open your browser at `http://localhost:3000`.

### Vue
1. Navigate to the `vue-app` directory.  
2. Install dependencies with:  
   ```bash
   npm install
   ```  
3. Start the application:  
   ```bash
   npm run serve
   ```  
4. Open your browser at `http://localhost:8080`.

### Angular
1. Navigate to the `angular-app` directory.  
2. Install dependencies with:  
   ```bash
   npm install
   ```  
3. Start the application:  
   ```bash
   ng serve
   ```  
4. Open your browser at `http://localhost:4200`.
